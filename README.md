# akimio 的小窝

这是 `https://imwsy043.github.io/` 的完整 Astro 博客源码。

日常使用只需要三个命令：

```powershell
pnpm.cmd install
pnpm.cmd dev
pnpm.cmd run deploy
```

- `pnpm.cmd install`：第一次使用时安装依赖。
- `pnpm.cmd dev`：在本地预览。
- `pnpm.cmd run deploy`：构建网站、保存源码到 `main`，并发布成品到 `gh-pages`。

完整的写文章、换图片和发布步骤见 [BLOG_GUIDE.md](./BLOG_GUIDE.md)。
